CONTENT OS landing page
=======================

Files:
- index.html: complete responsive landing page
- assets/: screenshots supplied in the conversation

Before publishing:
1. Open index.html in a code editor.
2. Find `const WHATSAPP_NUMBER = "212600000000";`
3. Replace it with your Moroccan number in international format, without +, spaces, or the leading 0.
   Example format: 2126XXXXXXXX
4. Open index.html in your browser to preview.

Deploy free with Netlify:
1. Go to https://app.netlify.com/drop
2. Sign in or create a free account.
3. Drag the entire `content_os_landing` folder (or unzip the ZIP and drag the folder contents) into the drop area.
4. Netlify will publish a temporary `*.netlify.app` address.
5. You can change the site name in Netlify site settings.

The page currently uses WhatsApp as the contact/checkout path and asks visitors to request current pricing. It does not process payments.
